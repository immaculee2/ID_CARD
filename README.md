# ID Card Generator

A simple React web application to generate ID cards dynamically using **React**, **Vite**, and **Tailwind CSS**.

---

## Features

- Reusable **IdCard** component for each person  
- Dynamic rendering of multiple cards via `.map()`  
- Props used to pass data from `App.jsx` to `IdCard.jsx`  
- Styled with Tailwind CSS (borders, shadows, spacing)
